# Common brief, round 5: the 1996+ design and pseudo real time (read first)

Read `../followup2/COMMON.md` (project context and hard rules; they all still apply: no FOMC-window surprise identification, write only into your own folder `followup3/<name>/`, pre-specify design, count tests, HAC/block bootstrap for overlapping 12-month outcomes, report nulls, `RESULT.md` max 600 words, reply with a 6-line summary), then `../followup2/SUMMARY.md`, `../reviews/OUTSIDE_MEMBER.md` and the 'Round 5' sections of `../reviews/ADVISOR_A.md` and `ADVISOR_B.md`.

Why: the outside committee member's plan makes Note A a measurement-and-stance paper and says the results must hold on the 1996+ sample (the market weights come from announcements since 1996, Note B's sample starts in 1996, and the earlier headline VAR yardstick 0.65 is a pre-1990 number: 0.65, 0.39, -0.01 for 1976-89, 1990-2007, 2009-19). Both advisors agreed on the design:
- Weights: fixed 1996-2026 full-sample estimate is the baseline (they define the unit); show the drift with an EXPANDING window of announcements (first estimate about 2006-2010) and a 20-year rolling window as a descriptive path with bootstrap bands; say that 'out of sample' is not clean when the weights use later announcements. 2008-15 stays in; dropping it is a check.
- VAR / flow: 1973+ VAR with fixed weights (main; needs no announcements and five recessions) AND a 1996+ VAR (4 and 12 lags) as the check of the foundation claim.
- Stance / level-flow / purge / NFCI regressions: fixed sample plus recursive (expanding) forecast evaluation from the first feasible date; no rolling 20-year estimation windows (about two recessions per window).
- Checks table (one row each, same statistics): (a) main spec; (b) fixed 1996+ throughout (VAR and regressions); (c) 1973+ extrapolated sample; (d) excluding 2008-15; (e) weights through 2019 only.
- A result 'holds up' if signs and rough size agree across rows, the weight path stays inside the baseline bootstrap band after 2010, expanding-window flows correlate above about 0.9 with the full-sample flows, and the VAR response does not change sign on 1996+. It fails if the weights leave the band after 2010, the 1996+ VAR response flips sign, or the r* step helps only before 1996.
- Pseudo real time: nothing in the package is real time now (weights full sample; r* one-sided but full-sample parameters; unemployment gap uses ex-post CBO NROU; CAPE from revised earnings; revised outcome data). Be honest: build what can be built, say what cannot, never use 'real time' in a title; say 'pseudo real time in the variables, not in the weights or r*' where true.
